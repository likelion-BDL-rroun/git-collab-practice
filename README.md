# Git 협업 실습

실제 툴이 아닌 연습용 저장소입니다. 공개 저장소라 누구나 볼 수 있으니 실제 키, 비밀번호, 개인정보는 올리지 마세요. 커밋에는 Git에 설정된 이메일도 함께 공개됩니다.

## 실습 순서

1. 저장소를 Clone하고 `이름/intro` 브랜치를 만든다.
2. `이름.md` 파일을 만들고 commit을 나눠서 한다. (예: 자기소개, 회사 근처 맛집)
3. push 한 후 `main`으로 pull request를 한다.
4. 앞사람의 pull request를 확인하고 Approve 리뷰를 남긴 뒤 병합한다. (첫 번째 사람은 마지막 사람 것을 리뷰한다.)
5. `main` 최신본을 받아 `이름/lunch` 브랜치를 만들고, 아래 `오늘의 점심:` 줄을 각자 다르게 고쳐 pull request를 한다.
6. 하나씩 병합하다가 충돌이 나면, AI에게 아래처럼 요청해 해결한다.

> `main`의 최신 내용을 내 브랜치에 합치고 충돌을 해결해줘. 두 사람의 의도가 부딪히는 부분은 임의로 고르지 말고 나에게 물어봐.
